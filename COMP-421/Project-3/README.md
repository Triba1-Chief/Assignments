# Project 3 — Database Application Logic

This project phase extends the digital eBook commerce database with application/database behavior. The included `creatives.sql` defines a DB2 trigger that reacts to a payment becoming successful and adds purchased eBooks to the customer's library when they are not already present. The file also includes a small test setup for exercising the trigger.

The full project report remains outside this public source folder because the submitted group document contains identifying information for multiple team members.
