# Final Project — Graph Pathfinding

Java graph/pathfinding project using a tile-based map.

Key concepts demonstrated:
- breadth-first search (BFS)
- depth-first search (DFS)
- weighted graph construction
- a custom min-priority queue
- Dijkstra-style shortest-path computation
- distance- and time-weighted paths
- constrained safest-shortest-path reasoning

Core implementation files in the submitted project include `Graph`, `GraphTraversal`, `TilePriorityQ`, `PathFindingService`, `ShortestPath`, `FastestPath`, and `SafestShortestPath`.

Tester packages, compiled output, IDE configuration, and course infrastructure are not part of the cleaned coursework presentation.
