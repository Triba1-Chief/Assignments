# Assignment 1 — Civilization

Java object-oriented programming assignment modeling a simplified civilization/unit system.

Key concepts demonstrated:
- inheritance and abstract classes
- unit subclasses such as workers, settlers, archers, and warriors
- tile-based state and unit placement
- polymorphic actions and equality logic
- collection management through a unit list

The uploaded source set also contained IDE/build output and testing kits; those are not part of the cleaned coursework view.
