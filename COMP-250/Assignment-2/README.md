# Assignment 2 — Gus the Caterpillar

Java data-structures assignment centered on a caterpillar whose body is represented as linked segments.

Key concepts demonstrated:
- linked structures
- stacks of previously occupied positions
- state transitions through evolution stages
- movement and collision/entanglement handling
- overloaded eating behavior for different food types
- randomized color changes and growth behavior

The primary student implementation is `Caterpillar.java`. Course-provided/support classes and tester files are kept out of the cleaned public view unless needed for context.
