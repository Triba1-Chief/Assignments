# COMP 302 — Programming Languages and Paradigms

Selected OCaml coursework from COMP 302.

## Homework

This folder contains ten OCaml homework files (`hw1.ml` through `hw10.ml`) covering the progression of functional-programming concepts used in the course, including recursion, higher-order functions, data structures, continuation-passing style, streams, parsing/interpreters, and type-related exercises.

Practice/playground files, exams, and course PDFs are not included in the cleaned coursework view.
