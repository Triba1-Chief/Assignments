# Assignment 3

This assignment covers graph algorithms and optimization problems, including iterative DFS over a grid, directed-cycle detection, minimum-spanning-tree style reasoning over Euclidean distances, and Ford–Fulkerson maximum flow using augmenting paths and a residual graph.

The cleaned source keeps the implementation and the graph support class required by the flow algorithm, while excluding test files, sample-output files, compiled output, and the assignment PDF.
