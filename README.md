# McGill Computer Science Coursework

Coursework is organized by course, then by assignment.

## Courses

- [COMP 206](./COMP-206/) — Introduction to Software Systems
- [COMP 250](./COMP-250/) — Introduction to Computer Science
- [COMP 251](./COMP-251/) — Algorithms and Data Structures

Each assignment has its own folder so source files, documentation, tests, and supporting material can be added without cluttering the course root.

> Coursework is shared as a record of academic work. Current-course solutions should remain private when required by course or academic-integrity policies.
