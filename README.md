## Repository Structure

Each course folder contains selected source code, design artifacts, tests, or supporting files where they add context. Large submission archives, IDE metadata, compiled output, generated documentation, and instructor-provided handouts are intentionally omitted where possible.

Collaborative course projects that have their own repositories are linked from the relevant course README rather than duplicated here.

> Coursework is shared as a record of academic work. Current-course solutions should remain private when required by course or academic-integrity policies.
